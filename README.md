# 🏁 کف‌خواب ریسینگ — KAFKHAB RACING

یک بازی ماشین‌سواری **سه‌بعدی** کامل که تماماً با WebGL خام و JavaScript بدون هیچ وابستگی،
کتابخانه یا فایل مدل/تکسچر خارجی ساخته شده است. **هر پیکسل و هر چندضلعی در لحظه‌ی اجرا،
به‌صورت رویه‌ای (procedural) تولید می‌شود.**

> ۲۰ پیست ایرانی · ۱۶ خودرو · مسابقه‌ی تک‌نفره و **دونفره‌ی محلی (صفحه‌ی تقسیم‌شده)**
> · گاراژ، خرید، رنگ و تقویت · رکورد و سکه · صدا و موسیقی کاملاً سنتزشده

[پیش‌نمایش زنده] — یا اجرا با: `node tools/serve.js` و بازکردن `http://localhost:8080`

## ▶️ اجرا

**بدون هیچ ابزاری:** روی `index.html` دوبار کلیک کن.
**یا با سرور محلی:**
```
node tools/serve.js        # http://localhost:8080
```

## 🧪 آزمون (بدون مرورگر)
کل بازی — ساخت پیست/خودرو، فیزیک، AI، رندرر، HUD و منوها — با یک WebGL و DOM ساختگی
اجرا و راستی‌آزمایی می‌شود:
```
node tools/headless-test.js      # یا  npm test
```

## 🖥️ ساخت EXE ویندوز
```
npm install
npm run build:win       # خروجی: dist/Kafkhab Racing-win32-x64/
```
(روی لینوکس/مک هم می‌توان برای ویندوز خروجی گرفت.)

## 🤖 ساخت APK اندروید
```
bash tools/build-android.sh     # نیازمند Android SDK + JDK 17 + Gradle
```
یا پوشه‌ی `android/` را در Android Studio باز کن.

## ⚙️ ساخت خودکار در GitHub
با هر `push`، ورک‌فلوی `.github/workflows/build.yml` موارد زیر را می‌سازد:
- آزمون هدلس (`test`)
- `KafkhabRacing-android.apk` (`android`)
- `KafkhabRacing-win-x64.zip` (`windows`)

و با تگ `v*` یک **Release** شامل هر دو بایناری منتشر می‌شود.

## 🗂️ ساختار
```
js/util.js       ریاضیات، RNG قطعی، سازنده‌ی مش
```
