# PHANTOM OPS X — ULTRA PACK (add-on)

> **این افزونه اختیاری است.** بازی پایه کامل و قابل بازی است و هیچ‌چیز از گرافیک به‌صورت
> «قفل‌شده» فروخته نمی‌شود. بستهٔ الترا فقط کیفیت بصری را بالا می‌برد و آزادانه قابل حذف است.

Optional, **100 % procedurally authored** graphics add-on for PHANTOM OPS X. Nothing is
downloaded from asset stores and no third-party art is resold here: every texel and every
vertex is generated by the Python pipeline in `generator/`, so the pack is ours to ship.

## What is inside the archive (18 MB)

| Content | Detail |
|---|---|
| 8 PBR material sets | albedo · tangent-space normal · metallic-roughness (glTF packed G/B) · emissive, 1024², `carbon`, `steel`, `neon`, `gold`, `glass`, `camo`, `panel`, `concrete` |
| 6 3D models (GLB) | `rifle_ultra` 9 444 tris · `operator_ultra` 13 118 · `tower_ultra` 6 652 · `crate_ultra` 2 040 · `drone_ultra` 1 864 · `sidearm_ultra` 1 780 — **34 898 triangles total** |
| 1 equirect sky | 2048 × 1024 neon-dusk environment, used for image-based lighting + PMREM |
| `pack.json` | manifest with per-file SHA-256, counts and provenance |

27 262 976 texels and 34 898 triangles, all built from analytic primitives (rounded-box SDF
ray marching, lofted superellipse sections, swept tubes) and noise-based shading.

## How the game uses it

1. `app/js/ultra.js` downloads the archive from the GitHub release that hosts it.
2. The archive SHA-256 is checked **before** anything is unpacked; then every file listed in
   `pack.json` is checked again.
3. The archive is cached (Cache API / `phantom-ultra-v1`) so the pack is instant — and offline —
   afterwards.
4. Textures are bound as real `MeshStandardMaterial` maps, GLB models are parsed by the
   dependency-free reader in `app/js/ultra-glb.js`, and the sky becomes `scene.environment`
   through `PMREMGenerator` plus an ACES tone map and PCF soft shadows.

The base install stays light: **no** texture, model or sky ships inside the APK — the add-on
is ~18 MB that the player chooses to download.

## Rebuild / republish

```bash
pip install -r generator/requirements.txt
cd generator && python3 build_pack.py --out ../dist --size 1024
# → dist/phantom-ultra-v1.0.0.zip, dist/pack.json, dist/SHA256SUMS.txt
```

CI does exactly this in `.github/workflows/phantom-ultra.yml`, verifies the archive with the
in-game ZIP reader and tests, builds the Android APK, and publishes one release containing:

* `phantom-ultra-v1.0.0.zip` — the add-on
* `ultra-catalog.json` — the catalogue the game reads (URL + size + SHA-256)
* `PhantomOpsX-Ultra-debug.apk` — the light-base install
* `PhantomOpsX-ultra-reel.mp4` — the vertical promo reel rendered offline

## Honest limits

* The add-on needs one network round-trip to install (GitHub). The game itself, the add-on
  management UI and all matches work offline.
* Textures are procedurally authored, not scanned photogrammetry — they are original art with
  real PBR channels, not photographs.
* 34 898 triangles are used for hero assets and props; enemy bots keep the lighter procedural
  rig with the same PBR materials so mobile frame-times stay reasonable.
