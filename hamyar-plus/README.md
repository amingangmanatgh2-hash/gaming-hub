# 📚 همیار پلاس | Hamyar Plus

جواب فعالیت‌ها، تمرین‌ها و **گام‌به‌گام همهٔ درس‌های پایهٔ اول تا دوازدهم** — با الهام از همیار، ولی پیشرفته‌تر و تمیزتر: فقط پایه‌های ۱ تا ۱۲ و درس‌هایشان، بدون تبلیغ و حاشیه‌های اضافه.

**یک هستهٔ واحد، چهار خروجی:** سایت Cloudflare ‏· اپ اندروید (APK) ‏· برنامهٔ ویندوز (EXE) ‏· اجرای کاملاً لوکال/آفلاین — همه از یک بانک محتوای واحد تغذیه می‌شوند.

## ✨ امکانات (فراتر از سایت‌های معمول جواب درس)

- 🎒 پوشش کامل **پایهٔ ۱ تا ۱۲** (دبستان، متوسطه اول و دوم + رشته‌های ریاضی‌فیزیک / تجربی / انسانی در پایه‌های ۱۰ تا ۱۲)
- ✍️ برای هر فصل: خلاصهٔ درس، **نکات کلیدی** و **پرسش‌وپاسخ گام‌به‌گام با توضیح** (اول حدس بزن، بعد جواب را باز کن)
- 🔎 **جستجوی سراسری و فوری** در همهٔ فصل‌ها و پاسخ‌ها
- 🎯 **آزمون از خودت**: سوال تصادفی از هر پایه/درس، خودتصحیحی و رکورد بهترین رشتهٔ پاسخ درست
- ⭐ نشان‌کردن درس‌ها، ✅ پیگیری پیشرفت مطالعه و ادامهٔ مطالعه (همه روی دستگاه خودت)
- 📴 **کاملاً آفلاین**: کل بانک سوال زیر ۲۰۰ کیلوبایت است و داخل اپ/مرورگر کش می‌شود
- ☁️ **همگام با سایت**: هر وقت اینترنت باشد، بانک سوال از سایت شما تازه می‌شود (بدون نیاز به آپدیت اپ)
- 🌙 حالت تاریک/روشن، اندازهٔ فونت قابل تنظیم، PWA قابل نصب روی موبایل، راست‌چین با فونت وزیرمتن

## 🔁 اپ دقیقاً چطور آنلاین/آفلاین کار می‌کند؟

```
باز شدن اپ (APK یا EXE)
   └─ چک کردن سایت:  GET {SITE}/api/v1/client/bootstrap   (حداکثر ~۴ ثانیه)
        ├─ پاسخ سالم  ← نسخهٔ آنلاینِ سایت باز می‌شود (همیشه تازه) 🟢
        └─ بی‌پاسخ/بدون نت ← نسخهٔ سبک لوکال داخل اپ بالا می‌آید 📦
               └─ هر ۳۰ ثانیه + هنگام برگشت شبکه دوباره چک می‌کند
                  و بی‌صدا به حالت آنلاین سوئیچ می‌کند
```
نسخهٔ وب هم همین است: اول از کش/دادهٔ لوکال سریع باز می‌شود، پشت صحنه `/api/catalog` را می‌گیرد و اگر تازه‌تر بود جایگزین می‌کند. آدرس سایت هم از «تنظیمات» داخل اپ قابل تغییر است.

## ▶️ اجرای لوکال (بدون هیچ حسابی)

```bash
cd hamyar-plus
npm run dev        # http://localhost:8899  (سایت + API با یک سرور سبک Node)
npm test           # تست بانک محتوا + API + منطق اپ‌ها
```

## ☁️ دپلوی روی Cloudflare

### راه ۱ — Workers (پیشنهادی، سایت + API با یک دستور)
```bash
cd hamyar-plus
npx wrangler login          # یک بار
npm run deploy              # node tools/build-catalog.mjs && wrangler deploy
# خروجی: https://hamyar-plus.<حساب‌تو>.workers.dev
```

### راه ۲ — Pages
```bash
cd hamyar-plus
node tools/build-catalog.mjs
npx wrangler pages deploy . --project-name hamyar-plus   # public/ به‌همراه functions/ (همان API)
# نکته: در داشبورد Pages، «Build output directory» را روی public بگذارید.
```
> در داشبورد Cloudflare هم می‌توانید همین مخزن را وصل کنید: Build command ‏`cd hamyar-plus && node tools/build-catalog.mjs`‏ و خروجی `hamyar-plus/public`.

### API
| مسیر | کاربرد |
|---|---|
| `GET /api/health` | سلامتی + نسخه و شمارنده‌ها |
| `GET /api/v1/client/bootstrap` | نقطهٔ اتصال APK/EXE برای تشخیص آنلاین بودن سایت |
| `GET /api/catalog` | کل بانک محتوا (برای همگام‌سازی اپ‌ها، CORS باز، کش لبه) |
| `GET /api/grade/:id` · `/api/subject/:id` · `/api/lesson/:id` | دریافت تکی |
| `GET /api/search?q=...` | جستجو سمت سرور |

## 📱🪟 ساخت APK و EXE وابسته به سایت

بعد از دپلوی، آدرس واقعی سایت را موقع بیلد بدهید تا داخل اپ سوار شود (بدون آن هم اپ‌ها لوکال کار می‌کنند و آدرس از داخل اپ قابل ورود است):

```bash
export HAMYAR_SITE_ORIGIN=https://hamyar-plus.<حساب‌تو>.workers.dev
cd hamyar-plus && npm run sync          # گذاشتن نسخهٔ لوکال + آدرس سایت داخل هر دو اپ

# اندروید (نیازمند JDK 17 و Android SDK)
cd clients/android && gradle :app:assembleDebug

# ویندوز (روی ویندوز یا CI)
cd clients/desktop && npm ci && npm run dist
```

**راه ساده‌تر — گیت‌هاب اکشن:** ورک‌فلوی «همیار پلاس» (`.github/workflows/hamyar-plus.yml`) با هر پوش روی این برنچ یا به صورت دستی (`workflow_dispatch` با ورودی `site_origin`) تست می‌گیرد، **APK + EXE** می‌سازد و **GitHub Release** منتشر می‌کند. با روشن‌کردن `deploy_cloudflare` و گذاشتن سکرت‌های `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` دپلوی سایت هم خودکار انجام می‌شود.

## 🗂️ ساختار پروژه

```
hamyar-plus/
├─ content/            # ✏️ محتوای آموزشی دست‌نوشت (پایه‌های ۱-۶، ۷-۹، ۱۰-۱۲)
├─ tools/
│  ├─ build-catalog.mjs  # ساخت و اعتبارسنجی بانک محتوا → public/data/catalog.{json,js}
│  ├─ sync-assets.mjs    # کپی نسخهٔ لوکال + آدرس سایت داخل APK و EXE
│  └─ dev-server.mjs     # سرور لوکال بدون Cloudflare
├─ public/            # خودِ وب‌اپ (سایت + PWA + نسخهٔ لوکال داخل اپ‌ها)
├─ worker/            # Cloudflare Worker و API مشترک
├─ functions/         # همان API برای Cloudflare Pages
├─ clients/
│  ├─ android/        # پوستهٔ اندروید (WebView هیبرید آنلاین/لوکال)
│  └─ desktop/        # پوستهٔ ویندوز (Electron هیبرید آنلاین/لوکال)
├─ tests/             # تست‌های Node
└─ wrangler.toml
```

## ✏️ اضافه‌کردن سوال و درس

1. فایل پایهٔ مربوط در `content/` را باز کن و مثل بقیه، با قالب `L(عنوان، خلاصه، نکات، [[سوال، جواب، توضیح], ...])` درس اضافه کن.
2. `version` را در `tools/build-catalog.mjs` (مقدار `catalog.version` با ویرایش `updatedAt` یا شماره نسخه در سازنده) به‌روز و `npm run catalog` را اجرا کن — اعتبارسنجی خودکار جلوی دادهٔ ناقص را می‌گیرد.
3. سایت را دوباره دپلوی کن؛ اپ‌های نصب‌شده دفعهٔ بعد که آنلاین شوند خودشان محتوای تازه را می‌گیرند. نیازی به ارسال آپدیت APK/EXE نیست. 🎉

> محتوای فعلی «هستهٔ آغازین» است: هر ۹۰ کتاب درسی پایه‌های ۱ تا ۱۲ با فصل‌بندی و برای هر فصل خلاصه، نکات و پرسش‌وپاسخ‌های توضیح‌دار (در مجموع ۱۶۹ فصل و ۳۴۸ پرسش)؛ طوری طراحی شده که با ویرایش فایل‌های `content/` بی‌نهایت بتوانید گسترشش بدهید — مثلاً جواب تک‌تک صفحه‌های کتاب‌ها را فصل‌به‌فصل اضافه کنید.

## 🔒 امنیت و حریم خصوصی

- هیچ راز/توکنی داخل APK یا EXE نیست؛ فقط **نشانی عمومی** سایت (که در تنظیمات اپ هم قابل تغییر است).
- نشانی سایت سخت‌گیرانه اعتبارسنجی می‌شود (فقط `https` عمومی، بدون مسیر/رمز) و پاسخ bootstrap باید دقیقاً متعلق به همان مبدأ و برنامهٔ `hamyar-plus` باشد.
- پیشرفت، نشان‌ها و رکوردها فقط روی دستگاه کاربر (`localStorage`) می‌ماند؛ سرور هیچ دادهٔ شخصی جمع نمی‌کند.
