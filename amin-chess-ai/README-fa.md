## 🖥 اجرا در مرورگر (وب)

پیش‌نیاز: Node.js 18+

```bash
cd amin-chess-ai
npm install
npm run build       # ساخت نسخه وب در پوشه www/ (همه منابع داخلی، بدون CDN)
npm run serve       # اجرا روی http://localhost:8788
```

بعد از اولین بارگذاری، دفعه‌های بعد **بدون اینترنت** هم کار می‌کند (Service Worker).

## 🧪 تست‌ها

تست‌های واقعی اجرا می‌شوند با:

```bash
npm test
```

- **تست معماها** — با chess.js صحت هر معما (مات واقعی، مات اجباری، سود تاکتیکی بهینه) تأیید می‌شود.
- **تست درس‌ها** — قانونی بودن همه دموها و تمرین‌ها، صحت آزمون‌ها.
- **تست دود jsdom** — کل برنامه (index.html + همه اسکریپت‌ها) واقعاً در jsdom با IndexedDB واقعیِ fake-indexeddb اجرا می‌شود؛ ناوبری به ۱۰ صفحه، اقتصاد سکه (دریافت/خرج/جلوگیری از دوباره‌گیری) و قوانین شطرنج تست می‌شوند.

## 📱 ساخت APK با GitHub Actions

### ۱. قرار دادن پروژه در GitHub

```bash
# محتوای پوشه amin-chess-ai را در مخزن خودت قرار بده
# (یا اگر این پوشه داخل مخزن بزرگ‌تر است، workflow موجود را اجرا کن)
git init
git add .
git commit -m "AMIN CHESS AI — نسخه اول"
git remote add origin https://github.com/<YOUR-USER>/<YOUR-REPO>.git
git push -u origin main
```

> نکته: پوشه `.github/workflows/android-build.yml` **داخل همین پوشه** هم هست؛ اگر کل پوشه را به‌تنهایی مخزن کردی، آن را به ریشه مخزن منتقل کن:
> ```bash
> mkdir -p .github && mv .github/workflows .github-tmp 2>/dev/null || true
> ```
> یا ساده‌تر: مسیر workflow را همان‌جا که هست نگه دار — در workflow مسیر `working-directory: amin-chess-ai` تنظیم شده که برای مخزن کامل (این repo) درست است. برای مخزن مستقل فقط آن خط را حذف کن.

### ۲. فعال‌سازی Actions و اجرای Build

1. در GitHub وارد تب **Actions** شو؛ اگر پیام فعال‌سازی بود، دکمه **I understand my workflows, go ahead and enable them** را بزن.
2. در سمت چپ workflow با نام **«ساخت APK شطرنج امین»** را انتخاب کن.
3. دکمه **Run workflow ▾** → **Run workflow** را بزن.
4. ۵ تا ۸ دقیقه صبر کن (نصب Node، تست، ساخت وب، `cap sync`، Java 17، Android SDK، Gradle Build).

روی `push` به `main`/`master` هم به‌طور خودکار Build می‌شود.

### ۳. دانلود APK

در صفحه اجرای workflow، پایین بخش **Artifacts** دو فایل می‌بینی:

- **amin-chess-debug-apk** → `app-debug.apk` — برای نصب مستقیم روی گوشی (تنظیمات → اجازه نصب از منابع ناشناس).
- **amin-chess-release-apk** → `app-release.apk` (امضاشده اگر Secrets تنظیم کرده باشی، در غیر این صورت unsigned).

هر Artifact به‌صورت ZIP دانلود می‌شود؛ APK داخل آن است.

### ۴. ساخت نسخه Release امضاشده + تنظیم Secrets

**گام الف — ساخت Keystore روی کامپیوتر خودت:**

```bash
keytool -genkeypair -v \
  -keystore amin-chess.keystore \
  -alias amin-chess \
  -keyalg RSA -keysize 2048 -validity 10000
```

**گام ب — تنظیم Secrets در GitHub:**

مسیر: **Repo → Settings → Secrets and variables → Actions → New repository secret**

| نام Secret | مقدار |
|---|---|
| `AMIN_CHESS_KEYSTORE` | محتوای فایل keystore به‌صورت **Base64** → `base64 -w0 amin-chess.keystore` |
| `AMIN_CHESS_KEY_PASSWORD` | رمز Keystore |
| `AMIN_CHESS_KEY_ALIAS` | `amin-chess` |

> ⚠️ فایل keystore و رمز آن **هرگز** در مخزن قرار نگیر — فقط از Secrets استفاده می‌شود. Workflow در نبود Secrets، Release را بدون امضا می‌سازد و برنامه نمی‌شکند.

## 🔑 راهنمای مدیریت API

صفحه **«مدیریت هوش مصنوعی و API»** داخل برنامه (از پروفایل یا تنظیمات):

### Cloudflare (سرویس اصلی)

1. به [dash.cloudflare.com](https://dash.cloudflare.com) برو → **Workers & Pages** → یک حساب بساز.
2. **Account ID** را کپی کن (سمت راست صفحه Workers).
3. **My Profile → API Tokens → Create Token** → قالب «Edit Cloudflare Workers AI» یا دسترسی `Workers AI Read/Run` بساز.
4. در برنامه: Account ID و Token را وارد → **تست اتصال** → **ذخیره**.

### Groq (اختیاری)

1. به [console.groq.com](https://console.groq.com) برو → API Key بساز.
2. در برنامه: کلید را وارد → تست → مدل را انتخاب کن (Llama 3.1 Instant سریع / Llama 3.3 70B قدرتمند) → فعال کن.

### منطق انتخاب سرویس

- فقط Cloudflare → همه‌چیز با Cloudflare کار می‌کند.
- فقط Groq → گفت‌وگو با Groq (در صورت پشتیبانی مدل).
- هیچ‌کدام → **همه امکانات آفلاین** فعال است؛ استاد شطرنج صادقانه می‌گوید مدل زبانی آنلاین در دسترس نیست و از Stockfish + پایگاه دانش استفاده می‌کند.
- اگر سرویس آنلاین وسط کار قطع شود، خودکار به پاسخ آفلاین برمی‌گردیم و به کاربر اعلام می‌شود.

> 🔒 **امنیت:** توکن‌ها فقط در IndexedDB همین دستگاه ذخیره می‌شوند و در هیچ فایل عمومی/کد مخزن نیستند. برای نگه‌داشتن توکن‌ها کامل بیرون از مرورگر، بخش بعدی را بخوان.

## ☁️ بک‌اند امن Worker (اختیاری)

پوشه `worker/` یک Cloudflare Worker آماده است که توکن‌ها را در Secrets خودش نگه می‌دارد و فقط `/api/chat` را برای اپلیکیشن باز می‌کند:

```bash
cd worker
npm install -g wrangler
wrangler login
wrangler secret put CF_ACCOUNT_ID
wrangler secret put CF_API_TOKEN
wrangler secret put GROQ_API_KEY    # اختیاری
wrangler deploy
```

سپس آدرس Worker را می‌توانی به‌عنوان پروکسی استفاده کنی (RATE LIMIT داخلی: ۲۰ درخواست در دقیقه برای هر IP).

## 🔍 نکات فنی و صداقت فنی

- **قوانین شطرنج** با کتابخانه معتبر chess.js پیاده شده — نه کد دستی ناقص.
- **Stockfish واقعی** داخل Web Worker؛ سطح‌ها با `Skill level` و `movetime` واقعی تنظیم می‌شوند. در مرورگرهای بدون WASM، پشتیبان asm.js به‌طور خودکار استفاده می‌شود.
- **تحلیل اشتباهات** با مقایسه امتیاز موتور قبل/بعد از هر حرکت (MultiPV) انجام می‌شود؛ آستانه‌ها: ۶۰/۱۲۰/۳۰۰ سنتی‌پان.
- **سکه‌ها** فقط از راه تراکنش‌های معتبر ثبت‌شده در IndexedDB تغییر می‌کنند؛ `reasonKey` یکتا از دوباره‌گیری جایزه جلوگیری می‌کند.
- **هیچ پرداخت واقعی** در برنامه نیست؛ همه خریدها با سکه مجازی است.
- اگر WebWorker موتور در مرورگر هدف اجرا نشود، بنر شفاف نمایش داده می‌شود — هیچ قابلیت جعلی ادعا نمی‌شود.
- روی اندروید، WebView مدرن WASM را کامل پشتیبانی می‌کند.
