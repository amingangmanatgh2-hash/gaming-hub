# راهنمای تنظیم API — AMIN CHESS AI

این راهنما برای صفحه **«مدیریت هوش مصنوعی و API»** داخل برنامه است.

## منطق کلی

- هیچ API اجباری نیست. بدون هیچ توکنی، **تمام امکانات آفلاین** (بازی با موتور، تحلیل، معما، آموزش، فروشگاه و…) کار می‌کنند.
- توکن‌ها فقط روی دستگاه تو (IndexedDB) ذخیره می‌شوند و در هیچ فایل عمومی قرار نمی‌گیرند.
- Cloudflare سرویس اصلی است؛ Groq اختیاری و جایگزین.

---

## ۱) Cloudflare Workers AI (سرویس اصلی)

### دریافت مقادیر

1. حساب رایگان در [dash.cloudflare.com](https://dash.cloudflare.com) بساز.
2. **Account ID**: داشبورد → Workers & Pages → در صفحه Overview سمت راست «Account ID» را کپی کن (۳۲ کاراکتر هگز).
3. **API Token**: آیکون کاربر (بالا-راست) → **My Profile** → **API Tokens** → **Create Token**.
   - روش سریع: قالب آماده نیست، «Custom token» بساز با دسترسی:
     - **Account → Workers AI → Read** (برای تست اتصال)
     - **Account → Workers AI → Edit** (برای اجرای مدل‌ها)
   - Continue to summary → Create Token → مقدار را یک‌بار کپی کن (دوباره نشان داده نمی‌شود).

### داخل برنامه

- صفحه API → بخش Cloudflare:
  - Account ID را وارد کن.
  - Token را وارد کن (دکمه 👁 نمایش/مخفی‌کردن).
  - **تست اتصال** → باید «اتصال به Cloudflare برقرار است» ببینی.
  - **ذخیره تنظیمات** → وضعیت اتصال بالا صفحه سبز می‌شود.
- برای ویرایش، مقدارها را عوض کن و دوباره ذخیره؛ برای حذف، دکمه **حذف** (با تأیید).

## ۲) Groq (اختیاری)

1. به [console.groq.com](https://console.groq.com) برو و با حساب رایگان وارد شو.
2. **API Keys** → **Create API Key** → کپی کن (`gsk_...`).
3. داخل برنامه: کلید را وارد، **تست اتصال**، مدل را انتخاب کن:
   - `Llama 3.1 Instant` — سریع و کم‌مصرف (پیش‌فرض)
   - `Llama 3.3 70B` — قدرتمندتر و کمی کندتر
   - `Gemma 2 9B` — گزینه میانه
4. کلید **فعال‌سازی Groq** را روشن کن → **ذخیره**.
5. می‌توانی در «انتخاب سرویس فعال» Groq را به‌عنوان سرویس اصلی گفت‌وگو تعیین کنی.

## ۳) سرویس جایگزین و حالت‌ها

- **خودکار**: Groq اگر فعال باشد وگرنه Cloudflare وگرنه آفلاین.
- **Cloudflare فقط** / **Groq فقط** / **همیشه آفلاین** — هر وضعیتی مجاز است.
- اگر سرویس آنلاین وسط گفت‌وگو خطا بدهد، برنامه خودکار به پاسخ آفلاین (Stockfish + پایگاه دانش) برمی‌گردد و به‌صورت شفاف پیام «سرویس آنلاین پاسخ نداد» نمایش می‌دهد — وانمود نمی‌کند که مدل آنلاین داری.

## ۴) امنیت

- توکن‌ها فقط در `IndexedDB → amin-chess-ai → credentials` همین دستگاه هستند.
- توکن‌ها در `localStorage`، فایل HTML، یا هیچ خروجی قابل انتشار نیستند.
- توکن را در مخزن GitHub، اسکرین‌شات یا پیام‌ها قرار نده.
- برای حذف کامل: دکمه حذف هر سرویس، یا «پاک‌کردن همه داده‌ها» در پروفایل.

## ۵) بک‌اند امن (گزینه حرفه‌ای)

اگر می‌خواهی توکن‌ها حتی به مرورگر نروند، Worker همراه پروژه را مستقر کن:

```bash
cd worker
npm install -g wrangler
wrangler login
wrangler secret put CF_ACCOUNT_ID
wrangler secret put CF_API_TOKEN
wrangler secret put GROQ_API_KEY
wrangler deploy
```

این Worker فقط `/api/chat` را با Rate Limit ۲۰ درخواست/دقیقه برای هر IP باز می‌کند و توکن‌ها فقط در Secrets سرور می‌مانند.
