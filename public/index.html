✨ چرا هم‌کلام؟

  • پیام‌ها و فایل‌های سبک، بدون عبور از سرورهای گران
  • حالت کم‌مصرف (150p/12kbps) برای اینترنت ضعیف
  • اتاق خصوصی با رمز، قفل، اتاق انتظار و اخراج/مسدودی
  • بدون ثبت‌نام، بدون شماره تلفن، بدون تبلیغ
  • کد کامل روی GitHub؛ خودتان روی اکانت رایگان کلودفلر بالا بیاورید

۱۲۴ قابلیت، همه در یک اتاق

در ۹۰ ثانیه خودتان بالا بیاورید (کاملاً رایگان)

۱) یک‌کلیکی

با دکمهٔ زیر، کلودفلر یک نسخه از همین مخزن را در اکانت گیت‌هاب شما می‌سازد و روی اکانت رایگان خودتان منتشر می‌کند.

☁️ Deploy to Cloudflare

۲) با دستور (Workers — پیشنهادی)

git clone YOUR_REPO_URL hamkalam
cd hamkalam
npm install
npx wrangler login
npm run deploy

همین یک دستور، هم سایت استاتیک و هم سرور سیگنالینگ (Durable Objects) را منتشر می‌کند.

۳) اگر Pages می‌خواهید

# روی داشبورد: Workers & Pages → Create → Pages → Connect to Git
# Build command:      npm run build
# Build output dir:   public
# سپس Bindings → Durable Objects → ROOMS → Room

هر دو روش یک اپ می‌دهند؛ تفاوت فقط در محل بایند کردن Durable Object است.
