# معماری مدار

```text
مرورگر / PWA / پوستهٔ Android / پوستهٔ Windows
       │ HTTPS (همان دامنه)
       ▼
Cloudflare Worker ── Assets(public)
       ├── /api/v1/*  ── MarketState (یک Durable Object با storage)
       │                  ├─ تنظیمات، طرح‌ها، سفارش‌ها، نشست‌ها
       │                  ├─ UUIDهای دسترسی با تاریخ انقضا
       │                  └─ سه پیام آخر دستیار
       ├── /edge  ── VLESS-over-WebSocket ── cloudflare:sockets.connect(TCP 80/443)
       ├── Telegram webhook ── Telegram Bot API
       ├── Cron (اختیاری) ── منبع HTTPS نرخ دلار به تومان
       └── سرویس قبلی /meet و /api/room ── Room Durable Object
```

Pages اختیاری صرفاً فایل‌های استاتیک و Functions proxy را نگه می‌دارد؛ binding `CORE` به Worker لازم است. `MarketState` کلاس DO در Worker است، نه در Pages. برای کانفیگ روی دامنهٔ Pages، `EDGE_HOST` را به hostname ورودی TCP Worker وصل کنید.

## جریان‌ها

1. **اولین نصب:** Worker `SETUP_KEY` را از secret با مقدار کاربر مقایسه می‌کند. `MarketState` فقط یک‌بار salt/hash رمز (PBKDF2، ۱۵۰٬۰۰۰ دور)، تنظیمات و سشن را می‌نویسد. با توکن ربات، Worker پیش از ذخیره با کلید مشتق از `APP_SECRET` و AES-GCM رمز می‌کند. بدون `SETUP_KEY` نصب ممکن نیست.
2. **خرید پولی:** مشتری طرح را انتخاب می‌کند → DO قیمت USD × نرخ تومان را در سفارش snapshot می‌گیرد → شناسه و کد پیگیری تصادفی یک‌بار به کاربر داده می‌شود → مدیر پرداخت خارج از سایت را بررسی و با CSRF سفارش را تأیید می‌کند → UUID و توکن اشتراک با زمان انقضا ایجاد می‌شوند. مدیر می‌تواند دسترسی را برای اتصال‌های جدید باطل کند؛ سوکت از قبل باز تا قطع‌شدنش ممکن است ادامه داشته باشد. هیچ پرداختی توسط سایت انجام نمی‌شود.
3. **دسترسی رایگان:** درخواست با محدودیت تقریبی ۱ بار/۲۴ ساعت برای هش IP → UUID و توکن اشتراک با مدت طرح. محدودیت IP معادل quota و ضدتقلب قطعی نیست.
4. **اشتراک:** GET `/api/v1/sub/:token` چهار پروفایل ظاهری روی **همان hostname** تولید می‌کند؛ فرمت پیش‌فرض Base64 خطوط VLESS، با `?format=plain` یا `?format=json`. UUID محرمانه است؛ مسیرهای profile سرورهای جداگانه نیستند.
5. **تونل:** کلاینت VLESS به `/edge` WebSocket متصل می‌شود؛ Worker هدر دودویی VLESS را می‌خواند، UUID را در DO اعتبارسنجی می‌کند و فقط در صورت مقصد دامنهٔ عمومی با پورت ۸۰/۴۴۳، سوکت TCP خروجی باز می‌کند. UDP، IP مستقیم، TCP arbitrary port، NAT سیستم‌عامل، تشخیص «نت ملی» و تضمین شکست DPI **وجود ندارد**. سقف هر اتصال ۲۵۰ MB است (کلاینت باید اتصال جدید باز کند).
6. **AI:** پنل با CSRF context محدود را به binding `AI` می‌دهد، نتیجه را با allowlist روی server اعتبارسنجی می‌کند و تنها پس از تأیید مدیر اعمال می‌کند. بدون binding خطای صریح 503 دارد؛ حافظه سه پیام اخیر است.

## مرزهای ظرفیت

این یک نمونهٔ تک‌فروشگاهی کم‌حجم است: حداکثر ۱۲ طرح و ۲۰۰۰ سفارش در شاخص DO؛ صفحهٔ سفارش‌های پنل ۲۰۰ مورد آخر را نشان می‌دهد. دادهٔ جلسات/محدودیت‌های IP برای دمو نگهداری می‌شود و پاک‌سازی زمان‌بندی‌شدهٔ کامل ندارد؛ برای حجم/حریم خصوصی واقعی باید retention، D1/R2، محدودیت ترافیک و پرداخت معتبر اضافه شود. این «۲۰۰۰ سفارش» به معنی وجود ۲۰۰۰ سرور نیست. Cloudflare Anycast لبهٔ شبکه را خودکار انتخاب می‌کند؛ کاربر POP دلخواه یا ping تضمینی ندارد.

## تست‌ها

- `npm test` تست واحد نرخ/پروتکل، فرآیند end-to-end واقعی Worker + DO محلی با persistence مجزا، و تست‌های سرویس قدیمی را اجرا می‌کند.
- `npx wrangler deploy --dry-run` پیکربندی Worker و bundling را بررسی می‌کند.
- `npm run dev` برای مرور UI؛ اتصال خارج از کشور و API تلگرام در محیط توسعهٔ محدود تضمین/شبیه‌سازی نشده است.
