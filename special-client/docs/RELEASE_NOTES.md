# SPECIAL CLIENT 1.3.0-alpha.4 — نسخهٔ آزمایشی سبک‌تر

## تغییرات
- باگ اصلی شبکه، سقف ثابت فهرست نسخه‌ها، انتخاب عنوان به‌جای نسخه، cache و
  callbackهای worker اصلاح شدند. دانلود کاتالوگ در پس‌زمینه: GitHub ← Mojang ← cache.
- کاتالوگ واقعی رسمی در Release جداگانهٔ GitHub منتشر می‌شود؛ workflow روزانه
  بعد از قرارگرفتن روی default branch فعال است. نسخهٔ فرضی «26.3» ساخته نمی‌شود.
- پوشهٔ بازی جدا از `.minecraft`؛ در ویندوز ترجیح D/E/... قابل نوشتن، وگرنه پوشهٔ
  مستقل در home. فایل‌های ماینکرفت اصلی جابه‌جا یا پاک نمی‌شوند.
- حالت Lite پیش‌فرض، صفحه‌های اختیاری lazy، حذف اسکن تکراری هر ۴ ثانیه، توقف
  رندر کیپ/مانیتورینگ وقتی صفحه مخفی است، تم Graphite و منوی مرتب‌تر.
- اصلاح فرمت واقعی `options.txt` و کوئری سازگاری Modrinth؛ بدون وعدهٔ ۱۰۰۰ FPS.
- انتخاب منبع رسمی Sodium/LiquidBounce/Meteor/Wurst و Import JAR؛ نصب/سازگاری
  خودکار کلاینت‌های بیرونی نداریم. فایل‌های شخص ثالث را در ریپو کپی نکردیم.
- پنل Friends server: پذیرش EULA، دانلود سرور vanilla رسمی، Java/RAM، کنسول و
  توقف ملایم. اتصال اینترنتی دوستان نیازمند تنظیم شبکه است؛ تونل/پورت خودکار نداریم.
- ۱۲ طرح کیپ و رندر آزمایشی کیپ/بال متحرک در مود Fabric 1.20.1؛ اشتراک پروفایل
  عمومی UUID با دوستانی که همان مود را دارند. بازیکن وانیلا آن‌ها را نمی‌بیند.

## نصب
لانچر جدید را نصب کنید یا ZIP را کامل استخراج کنید. برای امکانات داخل بازی، JAR
قدیمی SPECIAL CLIENT را بردارید و `special-client-1.3.0-alpha.4.jar` را کنار Fabric
API مناسب در `mods` بگذارید. **مود سفارشی فقط Minecraft 1.20.1 / Fabric / Java 17**
است؛ نمایش نسخه‌های دیگر در لانچر به معنی سازگاری مود با آن‌ها نیست.

روی Play گزینهٔ Refresh catalogue را بزنید. بازی/JAR/assetها از منابع رسمی دانلود
می‌شوند؛ GitHub میزبان کاتالوگ است، نه همهٔ باینری‌های Minecraft. مسیر جدید بازی
ممکن است به دانلود دوباره نیاز داشته باشد؛ فایل‌های اصلی را خودکار کپی نمی‌کنیم.

## وضعیت تست
تست‌های خودکار، کامپایل و smoke رابط لانچر در CI بررسی می‌شوند. ورود Microsoft،
اجرای بازی، مصرف CPU/RAM واقعی، رندر کیپ/بال و اتصال دوستان به سرور هنوز به تست
دستی نیاز دارند. موفقیت ساخت، تضمین FPS، بدون‌بن‌بودن یا اتصال عمومی نیست.

راهنمای کامل: `LAUNCHER_LITE.md`. قابلیت‌های همراه/جمع‌آوری قبلی همچنان آزمایشی
و طبق محدودیت‌های `COMPANION.md` هستند. بسته‌ها امضای دیجیتال ندارند؛ هش‌ها کنارشان است.
