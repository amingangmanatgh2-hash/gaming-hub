# SPECIAL CLIENT 1.1.0-alpha.2 — Input & bridge practice

نسخهٔ آزمایشی؛ قبل از تست، از دنیاها بکاپ بگیرید و پوشهٔ بازی جدا بسازید.

## تغییرات
- منوی جدید **داخل بازی**: سایدبار، کارت، جست‌وجو، رنگ و دسته‌بندی ماژول‌ها.
- تبدیل هر کلیک واقعی به ۱/۲/۴/۸ درخواست ورودی؛ چپ و راست مستقل. بدون فشار
  اولیه کلیکی تولید نمی‌شود؛ نگه‌داشتن دکمه هم burst تازه ایجاد نمی‌کند.
  ورودی اضافه با فاصلهٔ چهار تیک ارسال به کنترل عادی بازی می‌شود؛ کول‌داون
  و قوانین سرور دور زده نمی‌شوند و تعداد ضربه/بلاک موفق تضمین نیست.
- آموزش ۱۰ روش بریج، هرکدام ۵ مرحله، با نمایش راهنما روی HUD.
- تمرین خودکار بریج صاف و هم‌سطح با sneak، **فقط تک‌نفرهٔ خصوصی**؛ مقصد XYZ،
  تنظیم نگاه به وجه بلاک و قراردادن با تعامل عادی بازی. مقصد می‌تواند در هوا
  باشد، اما بلاک‌گذاری باید به وجه موجود و در برد معمول متصل شود.
- **F8**: توقف تمرین و غیرفعال‌کردن چندکلیکی. WASD/Space هم تمرین را متوقف می‌کند.

## نصب
- ویندوز: `SPECIAL_CLIENT_Setup.exe` یا ZIP پرتابل را کامل استخراج و اجرا کنید.
- مود: `special-client-1.1.0-alpha.2.jar` فقط برای **Minecraft 1.20.1 + Fabric
  Loader + Fabric API + Java 17**. JAR قبلی SPECIAL CLIENT را از `mods` بردارید؛
  فقط یک نسخه باقی بماند. نصب لانچر به‌تنهایی مود را نصب نمی‌کند.
- منوی مود: Right Shift؛ تنظیم کلیک‌ها در Input و آموزش/تمرین در Practice.
- برای راهنمای کامل، README پوشهٔ client و `docs/BRIDGE_GUIDE_FA.md` را ببینید.

## محدودیت‌های مهم
- «آموزش گادبریج/تلی» به معنی اجرای خودکارشان نیست؛ اتوماسیون این نسخه فقط
  بریج صاف با sneak، حداکثر ۳۲ بلاک است. مسیر مورب/پله‌ای، فری‌کم و ده الگوریتم
  خودکار نداریم. تایید کد و ساخت CI جای تست واقعی بازی را نمی‌گیرد.
- چندکلیکی ورودی اضافه تولید می‌کند؛ ممکن است روی سرورها ممنوع باشد. تضمین
  «لجیت» یا «بدون بن» وجود ندارد. تمرین خودکار روی سرور/LAN فعال نمی‌شود.
- دست‌کاری پکت، افزایش reach، تغییر ضربه و دورزدن anti-cheat وجود ندارد.
  تعامل‌های عادی بازی طبیعتاً ترافیک عادی Minecraft دارند.
- کیپ داخل بازی و ورود Microsoft هنوز نیازمند کار/تست جداگانه‌اند.
- بسته‌ها امضای دیجیتال ندارند؛ هش‌ها در `SHA256SUMS.txt` هستند.

برای گزارش: مراحل بازتولید، نسخهٔ Windows/Java/Minecraft/Fabric و لاگ پاک‌سازی‌شده؛
توکن حساب یا دستور اجرای دارای توکن را نفرستید.
