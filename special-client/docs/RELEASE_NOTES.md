# SPECIAL CLIENT 1.0.0-alpha.1 — نسخهٔ آزمایشی

این نسخه برای تست است، نه انتشار نهاییِ تأییدشده در بازی.

## فایل‌ها
- `SPECIAL_CLIENT_Setup.exe`: نصب‌کنندهٔ ویندوز 10/11.
- `SPECIAL_CLIENT_Portable.zip`: نسخهٔ پرتابل؛ کل پوشه را استخراج کنید و سپس
  `SPECIAL_CLIENT.exe` را اجرا کنید، نه از داخل ZIP.
- `special-client-1.0.0.jar`: مود **Fabric / Minecraft 1.20.1 / Java 17**.
  به Fabric Loader و Fabric API سازگار نیز نیاز دارد؛ نصب لانچر به‌تنهایی مود را
  داخل بازی فعال نمی‌کند. این JAR برای Forge یا Minecraft 1.8.9 نیست.
- `SHA256SUMS.txt`: هش فایل‌ها برای بررسی صحت دانلود، نه امضای ناشر.

## شروع تست
1. قبل از تغییر مودها از دنیاها بکاپ بگیرید؛ ابتدا یک پوشهٔ بازی مجزا انتخاب کنید.
2. نسخهٔ پرتابل یا نصب‌کننده را اجرا کنید. بسته‌ها امضای دیجیتال ندارند؛ هش و
   منبع را بررسی کنید. این راهنما توصیه به خاموش‌کردن آنتی‌ویروس نمی‌کند.
3. Java مناسب و فایل‌های بازی باید نصب/دانلود شوند. ورود Microsoft، مالکیت بازی
   و دسترسی سرویس‌ها لازم است؛ جریان ورود واقعی هنوز دستی تست نشده است.
4. برای مود، Fabric 1.20.1 + Fabric API را در همان game directory نصب کنید و
   JAR مود را داخل `mods` بگذارید؛ نسخهٔ تکراری از مود باقی نگذارید.
5. داخل بازی Right Shift منو را باز می‌کند. پیش‌بینی پرتابه و هشدار بالای سر
   پیش‌فرض خاموش‌اند. کلید میانبرشان از Options > Controls قابل تنظیم است.

## محدودیت‌ها
- ساخت CI و تست‌های خودکار، جای تست دستی روی ویندوز و اجرای واقعی Minecraft
  را نمی‌گیرند. نصب/ارتقا/حذف و ورود آنلاین هنوز نیازمند تست دستی‌اند.
- پیش‌بینی پرتابه فقط تخمین برخورد با بلوک در هواست؛ آب، برخورد با موجودات،
  پراکندگی تصادفی و تغییرات سرور را مدل نمی‌کند. نشانگر، جهت روی HUD است، نه
  علامت سه‌بعدی دقیق داخل دنیا. هشدار بالای سر قصد حمله را تشخیص نمی‌دهد.
- تغییر پکت، افزایش برد ضربه و عملیات خودکار مبارزه وجود ندارد.
- کیپ‌ها فعلاً فقط تصویر و پیش‌نمایش لانچر هستند؛ رندر کیپ در بازی پیاده نشده.
- آفلاین فقط با فایل‌های محلی کامل و Java مناسب؛ جایگزین احراز هویت سرور نیست.
- برخی سرورها حتی overlay را ممنوع می‌کنند؛ قوانین سرور را رعایت کنید.

برای گزارش خطا: نسخهٔ Windows/Java/Minecraft/loader، مراحل بازتولید و لاگ
پاک‌سازی‌شده بفرستید؛ توکن Microsoft یا دستور اجرای دارای توکن را نفرستید.
