# SPECIAL CLIENT 1.2.0-alpha.3 — همراه اختیاری و جمع‌آوری تمرینی

نسخهٔ آزمایشی روی **Fabric / Minecraft 1.20.1 / Java 17**؛ «Fabric Plus» نام
غیررسمی امکانات پروژه است، نه یک loader جدا یا سازگاری با همهٔ نسخه‌ها.

## همراه
- پیشنهاد اختیاری راه‌اندازی API در اولین اجرای لانچر؛ قابل ردکردن و تغییر از
  Settings > Companion. OpenAI، Groq و API سفارشی سازگار با Chat Completions.
- کلید را فقط در فیلد رمز وارد کنید، نه چت. ذخیرهٔ جداگانه با DPAPI ویندوز،
  وابسته به همان endpoint؛ کلید قدیمی خودکار به سرویس جدید ارسال نمی‌شود.
- چت در لانچر و منوی داخل بازی؛ لانچر باید باز و game directory هر دو یکی باشد.
- خواندن جواب با صدای سیستم اختیاری و پیش‌فرض خاموش؛ میکروفون/مکالمهٔ صوتی ورودی نداریم.
- درخواست ابزار مدل فقط پیشنهاد است؛ کاربر در لانچر تایید می‌کند. اجرای کد/شل آزاد نداریم.

## جمع‌آوری محلی
- دکمه‌های Emerald/Diamond + return بدون API هم کار می‌کنند؛ فقط دنیای تک‌نفرهٔ
  خصوصی، نه سرور/LAN. F8 و حرکت دستی توقف می‌کنند.
- اسکن آیتم افتادهٔ موجود و در خط دید در چانک لودشده، حداکثر ۳۲ بلاک؛ نه دیدن کل
  مپ، تشخیص ژنراتورها یا «هرچه در کل سرور هست». مسیر‌یابی محدود روی سطح هم‌ارتفاع.
- در صورت فعال‌کردن Wool bridges و داشتن پشم در hotbar، حداکثر ۸ بلاک شکاف در
  هر مسیر با بریج مستقیم تمرینی ساخته می‌شود. قرارگیری به وجه واقعی و برد عادی نیاز دارد.
- حداکثر هشت هدف، سپس تلاش برای برگشت به نقطهٔ شروع. اگر مسیر/تکیه‌گاه/شرایط تغییر
  کند، توقف می‌کند؛ برگشت و جلوگیری از سقوط تضمین نمی‌شوند.

## نصب و تست
1. از دنیاها بکاپ بگیرید و یک دنیای تمرینی با کف امن بسازید.
2. نصب‌کننده یا پرتابل را اجرا کنید. بسته‌ها امضای دیجیتال ندارند؛ هش‌ها کنار فایل‌ها هستند.
3. JAR قبلی SPECIAL CLIENT را بردارید؛ `special-client-1.2.0-alpha.3.jar` و Fabric
   API مناسب را در `mods` همان game directory بگذارید؛ نصب لانچر به‌تنهایی کافی نیست.
4. Right Shift > Companion > Open chat؛ برای تست محلی هیچ API لازم نیست.
5. چند آیتم را روی کف هم‌سطح بیندازید و اول مسیر سادهٔ بدون شکاف را امتحان کنید.
6. بعد از تایید فرمان از لانچر، ظرف ۱۰ ثانیه فوکوس را به بازی برگردانید.

خواندن دنیا/حرکت/برداشت/برگشت، سرویس API واقعی و صدای سیستم هنوز نیاز به تست
دستی دارند. موفقیت ساخت و تست خودکار جای تست واقعی Minecraft نیست. این نسخه
بات همه‌کارهٔ بدوارز یا ابزار مخفی‌شدن از آنتی‌چیت نیست. دست‌کاری پکت اضافه نشده.
